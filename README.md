# Foot.DZ 7BS — نسخة البيانات الحقيقية

## المطلوب
1. ثبّت Node.js.
2. افتح هذا المجلد في Terminal.
3. نفّذ: `npm install`
4. انسخ `.env.example` إلى `.env`.
5. ضع مفتاح API-Football في `API_FOOTBALL_KEY`.
6. نفّذ: `npm start`
7. افتح `http://localhost:3000`.

الموقع يستخدم الخادم كوسيط حتى لا يظهر مفتاح API داخل JavaScript الخاص بالزوار.

مصدر البيانات: API-Football / API-Sports.
الدوريات المدمجة: Premier League 39، LaLiga 140، Serie A 135، Bundesliga 78، Ligue 1 61.
